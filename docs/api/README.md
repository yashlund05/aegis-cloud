# Aegis API Documentation

This directory will contain the OpenAPI specifications and detailed documentation for the Aegis microservices.

## Services
- **API Gateway**: Entrypoint for UI and external consumers.
- **Orchestrator**: Internal control loop management.
- **Telemetry Collector**: Interface for scraping/receiving metrics.
- **Predictor**: ML inference endpoints.
- **Decision Engine**: Request optimization plans.
- **Autoscaler / Node Power**: Actuation endpoints.
